# CodeCoach AI — Beginner Build & Submission Checklist

## A. Local setup
- [ ] Install Python 3.11+
- [ ] Install VS Code
- [ ] Install Git
- [ ] Open the CodeCoach-AI folder
- [ ] Create and activate `venv`
- [ ] Install `requirements.txt`
- [ ] Create `.env` with a Gemini API key
- [ ] Run `streamlit run app.py`

## B. First real runs
- [ ] Test a correct Python program
- [ ] Test Python division by zero
- [ ] Test a Python syntax error
- [ ] Test a C++ example
- [ ] Save actual outputs in `test-data/`
- [ ] Record pass/fail honestly

## C. Prompt engineering evidence
- [ ] Run the same test inputs with V1
- [ ] Run the same test inputs with V2
- [ ] Run the same test inputs with V3
- [ ] Compare clarity, correctness, hints and test cases
- [ ] Record observed results and counts
- [ ] Keep final prompt P1 unchanged during final tests

## D. Milestone 2 evidence
- [ ] At least 10 unique test rows, including 3 edge cases
- [ ] 2–3 screenshots of actual runs, captioned by test number
- [ ] Prompt iteration log with actual observations
- [ ] Module status table using Working / Partly working / Not started
- [ ] Technical report (1–2 pages)
- [ ] Architecture and workflow diagrams matching the built app
- [ ] Public GitHub repository and screenshot
- [ ] README and dated CHANGELOG
- [ ] 90–150 second real screen-recorded demo
- [ ] Milestone 2 PDF with all seven required sections
- [ ] Test every submission link in an incognito window

## E. Before GitHub push
- [ ] Confirm `.env` is not staged or committed
- [ ] Search files for API keys
- [ ] Confirm `.gitignore` is present
- [ ] Add only verified team and contribution details
